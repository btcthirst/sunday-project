# Посібник із тестування (Passport Desk MVP)

Цей документ містить план тестування та контрольні списки (checklists) для перевірки функціональності, безпеки та стабільності системи.

## 1. Тестування безпеки (Security)

Безпека є найважливішим компонентом системи.

### 1.1 Автентифікація та доступ
- [ ] **Перший запуск**: Перевірити, що при першому запуску з'являється форма створення оператора.
- [ ] **Майстер-ключ**: Перевірити, що після створення оператора з'являється модальне вікно з Майстер-ключем. Скопіюйте його для подальших тестів.
- [ ] **Автоблокування**: Залиште застосунок на 5 хвилин. Перевірте, чи з'являється екран блокування та чи вимагає він пароль.
- [ ] **Неправильний пароль**: Спробуйте увійти з неправильним паролем. Перевірте, чи з'являється помилка "Неправильний пароль".

### 1.2 Відновлення доступу (Master Key)
- [ ] **Скидання пароля**: На екрані входу натисніть "Забули пароль?".
- [ ] **Валідація ключа**: Введіть неправильний Майстер-ключ. Перевірте, чи з'являється помилка.
- [ ] **Успішне відновлення**: Введіть правильний Майстер-ключ та новий пароль. Перевірте, чи можете ви увійти з новим паролем.
- [ ] **Перевірка даних**: Після зміни пароля переконайтеся, що всі дані громадян (паспорти, ІПН) дешифруються коректно.

---

## 2. Функціональне тестування (Functional)

### 2.1 Облік громадян
- [ ] **Створення**: Додайте громадянина з обома типами паспортів (старий зразок "АА 123456" та ID-картка "123456789").
- [ ] **Валідація**: Спробуйте зберегти порожню форму або некоректну дату народження.
- [ ] **Шифрування**: Перевірте, що в списку громадян серія та номер паспорта відображаються частково приховано (наприклад, `АА ******`), якщо це налаштовано.
- [ ] **М'яке видалення**: Видаліть громадянина. Перевірте, чи зник він зі списку "Активні", але чи залишився в "Архіві" (видалені).
- [ ] **Відновлення**: Відновіть громадянина з архіву.

### 2.2 Склад сім'ї
- [ ] **Зв'язок**: Додайте Громадянина Б як "Сина" Громадянина А.
- [ ] **Реципрокність**: Перевірте профіль Громадянина Б — він має автоматично відображати Громадянина А як "Батька".
- [ ] **Видалення**: Видаліть зв'язок. Перевірте, чи зник він в обох профілях.

### 2.3 Реєстрація
- [ ] **Нова реєстрація**: Створіть постійну реєстрацію за новою адресою.
- [ ] **Автоматичне зняття**: Якщо у громадянина була попередня активна реєстрація, вона автоматично має отримати статус "Неактивна".
- [ ] **Зняття з реєстрації**: Виконайте процедуру зняття з реєстрації вручну.

## 3. Звіти та Документи

### 3.1 Генерація PDF
- [ ] **Довідка про реєстрацію**: Сгенеруйте PDF. Перевірте правильність відображення кирилиці та даних про адресу.
- [ ] **Довідка про склад сім'ї**: Перевірте, чи всі члени сім'ї включені в документ.

### 3.2 Експорт/Імпорт
- [ ] **Excel експорт**: Експортуйте список зареєстрованих громадян. Перевірте, чи файл відкривається в Excel/LibreOffice.
- [ ] **JSON Імпорт/Експорт**: Спробуйте експортувати базу громадян у файл та імпортувати її назад (на чистому застосунку).

---

## 4. Аудит та Логування

- [ ] **Журнал аудиту**: Виконайте будь-яку дію (наприклад, зміна адреси). Перейдіть у розділ "Журнал аудиту" та перевірте, чи з'явився там запис про вашу дію з правильним часом та іменем оператора.
- [ ] **Спроби входу**: Перевірте, чи фіксуються в журналі невдалі спроби входу.

---

## 5. Граничні випадки (Edge Cases)

- [ ] **Довгі імена**: Введіть дуже довге ПІБ (наприклад, 100 символів). Перевірте, чи не "ламається" інтерфейс таблиці.
- [ ] **Спеціальні символи**: Використовуйте апострофи та дефіси в іменах (наприклад, "Д'Артаньян").
- [ ] **Дублікати**: Спробуйте створити двох громадян з однаковим номером паспорта. Система має попередити або обробити це.
